# Neverfilmed

AI-native creative studio website: AI commercials, websites, apps, social media, reels, banners and product photography.

Live on GitHub Pages: https://malurosbolea-ux.github.io/neverfilmed/

- Game-style levels (Home, Work, Services, Studio, Pricing, Contact) with an intro flight, HUD and unlocks
- WebGL spiral of frames (Three.js), GSAP + ScrollTrigger + Lenis scroll scenes
- Generative ambient music and UI sounds (Web Audio), custom cursor with trail
- English / Spanish, chatbot, contact brief
